Où sont les fichiers d'Apache ?

CheminRôle
/var/www/html/Racine du site (DocumentRoot) : index.html, pages, dossiers.
/etc/apache2/apache2.confConfiguration principale (blocs <Directory>, AllowOverride).
/etc/apache2/conf-available/Configurations disponibles (ex : mon_alias.conf), activées par a2enconf.
/etc/apache2/sites-available/000-default.confSite par défaut : bloc <VirtualHost *:80>, ErrorDocument.
/var/log/apache2/access.logJournal de toutes les requêtes reçues.
/var/log/apache2/error.logJournal des erreurs du serveur.
.htaccessConfiguration locale d'un dossier (lue si AllowOverride All).

Dépannage

Permission denied

L'utilisateur courant n'a pas le droit d'écriture (w) sur le dossier ou le fichier. Vérifie avec whoami et ls -ld, puis corrige en root avec chown ou chmod.

403 Forbidden

Apache (utilisateur www-data) ne peut pas atteindre ou lire le fichier : il manque le droit x sur un dossier parent (chmod o+x), le droit r sur le fichier, ou une section <Directory> avec Require all granted.

Ma modification de configuration n'a aucun effet

Apache ne relit sa configuration qu'au systemctl reload apache2. Une nouvelle configuration dans conf-available doit aussi être activée avec a2enconf.

Job for apache2.service failed

Erreur de syntaxe dans un fichier de configuration : lance apache2ctl configtest pour trouver la ligne fautive.
